# Release Notes: M03 Cognitive Architecture

## Overview
Milestone 03 introduces the Cognitive Architecture and Tool Provider ecosystems. This release transitions the agent from a static pipeline into a dynamic, self-reflective system capable of maintaining context and interfacing with universally standardized tool protocols like MCP.

## Major Features

### Cognitive Layer
*   **Memory & Knowledge Systems:** Introduction of separated Short-Term (Memory) and Long-Term (Knowledge) storage interfaces.
*   **Context Builder & Retriever:** A pipeline for dynamically injecting relevant historical and factual context into LLM prompts while respecting strict token budgets.
*   **Reflection & Learning Engines:** The ability for the agent to analyze the outcome of `ExecutionPipeline` results, evaluate their utility, and selectively promote successful insights back into the Long-Term Knowledge store.

### Tool Provider Ecosystem
*   **Provider Abstraction:** Refactored tool discovery and registration so tools can originate from anywhere (Native, REST, Plugin).
*   **Model Context Protocol (MCP) Support:** Full, native architectural support for ingesting tools via the standardized MCP protocol. The agent core remains agnostic to the MCP protocol, interacting with it solely through the `MCPToolProvider` adapter.
*   **Dynamic Discovery:** Capabilities to hot-load and hot-remove tools via Discovery interfaces without mutating or stalling the active runtime pipeline.
*   **Deterministic Resolver:** Built-in semantic version resolution to handle tool name collisions across disparate providers seamlessly.

## Technical Notes
*   All implementations prioritize strict Interface Segregation.
*   Execution remains isolated within the `ExecutionPipeline`, which enforces permissions and validations irrespective of tool origin.
*   The architecture successfully passed the Final Architecture Gate integration suite (`src/agent/playground/index.ts`).
