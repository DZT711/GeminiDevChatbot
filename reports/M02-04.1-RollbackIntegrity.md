# M02-04.1: Rollback Integrity Fix Report

## Root Cause
The `ExecutionContext` and `RestoreStrategy` originally used the JavaScript spread operator (e.g., `{ ...this.temporaryVariables }`) to copy state into and out of `ExecutionSnapshot`. While this created a new top-level object or array, it only shallow-copied the nested values. Consequently, if a tool mutated a nested property within a variable or artifact, the mutation would bleed into the existing snapshots, destroying the immutability guarantee and breaking rollbacks.

## Design Decision
The `structuredClone` global function was chosen to enforce deep cloning of all mutable data structures (`temporaryVariables`, `environmentVariables`, `artifacts`, `outputs`, `warnings`, `errors`, `metadata`, `environment`, `scope`, and `customTags`). 

This approach is natively supported in modern JavaScript environments (Node.js and browsers) and safely handles cyclic references and built-in objects (like Maps and Sets) better than `JSON.parse(JSON.stringify())`. 

In `Restore.ts`, typecasting (`as string[]`) was used when restoring readonly arrays back to mutable ones to satisfy the TypeScript compiler while maintaining deep isolation.

## Files Modified
1. `src/agent/runtime/ExecutionContext.ts`
   - Modified `createSnapshot()` to use `structuredClone` for all deep objects and arrays.
2. `src/agent/checkpoint/Restore.ts`
   - Modified `DefaultRestoreStrategy.restore()` to use `structuredClone` when reading from the snapshot back into the context.

## Validation Performed
- **Build**: Successfully compiled.
- **Typecheck**: `tsc --noEmit` passed with no errors.
- **Lint**: `npm run lint` passed.
- **Behavioral Test**: A custom script (`test_rollback_integrity.ts`) was executed to:
  1. Create a context with nested mutable state.
  2. Create a snapshot.
  3. Mutate the original context deeply.
  4. Assert the snapshot remained unaffected (verifying snapshot isolation).
  5. Restore the context from the snapshot.
  6. Assert the context was correctly reverted.
  7. Mutate the snapshot deeply and assert the context remained unaffected (verifying restore isolation).
  - *Result*: The test passed successfully.

## Remaining Risks
- **Non-cloneable Objects**: `structuredClone` will throw an exception if an object contains functions or DOM nodes. If an `ExecutionVariable` or `ExecutionArtifact` stores uncloneable classes, this will crash. To mitigate this, tools must only store POJOs (Plain Old JavaScript Objects) or primitives in the ExecutionContext.

## Confirmation
Rollback snapshots are now completely structurally isolated. Checkpoints act as immutable historical records, and restoring them securely resets the execution context.
